# UFO Catcher 시뮬레이터 (2발톱)

일본 클레인 게임(UFO 캐처) 2발톱 모델의 3D 물리 시뮬레이터.
Three.js로 렌더링하고 Cannon-es로 강체 물리를 계산한다.
운영자 설정값(아암 힘·마찰·속도·경품 무게·assist 모드)을 실시간 슬라이더로 조정해
실제 기계의 거동과 비교 검증할 수 있도록 설계됨.

## 실행

빌드 단계 없음. 정적 파일 서버만 띄우면 된다.

```bash
cd ufo-catcher
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

또는 Node가 있으면:

```bash
npx serve -p 8000
```

> ES module + importmap 사용. `file://`로 직접 열면 CORS 차단됨.

## 조작

| 입력 | 동작 |
|---|---|
| `↑` / `W` | 클로 앞으로(-Z) |
| `↓` / `S` | 클로 뒤로(+Z) |
| `←` / `A` | 클로 왼쪽(-X) |
| `→` / `D` | 클로 오른쪽(+X) |
| `Space` | 드롭 시작 |
| 마우스 드래그 | 카메라 회전 |
| 스크롤 | 줌 |

`Space` 한 번 누르면 자동 시퀀스 진행: **하강 → 발톱 닫기 → 상승 → 구멍 위 이동 → 발톱 열림(낙하)**.
구멍에 떨어지면 `획득`, 도중에 떨어뜨리면 `실패`로 카운트.

## 우측 패널 — 운영자 설정

### 핵심 변수

| 항목 | 단위 | 기본 | 의미 |
|---|---|---|---|
| 아암 힘 | Nm | 3.0 | 힌지 모터 최대 토크. 작을수록 경품 무게에 밀려 발톱이 벌어짐(슬립). |
| 발톱 ↔ 경품 마찰계수 | — | 0.5 | 정/동 마찰 둘 다 이 값. 클수록 같은 힘에서 더 잘 잡힘. |
| 리프트 속도 | m/s | 0.4 | 클로 상승·하강 속도. 빠를수록 슬립 유발. |
| 이동 속도 | m/s | 0.5 | X·Z 평면 이동 속도. |
| 경품 무게 | kg | 0.20 | 모든 경품의 mass. 무거울수록 같은 힘에서 떨어짐. |
| 경품 개수 | — | 12 | 더미 안 경품 수. |

### 페이아웃 (assist) 모드

실제 기계의 “N회 실패 후 강한 모드” 동작을 모사.

- `アシスト 모드 활성화`: 켜면 활성.
- `aassist 발동 회수`: 연속 실패가 이 값에 도달하면.
- `아암 힘 (assist 발동 시)`: 그 회 한해 이 힘으로 잡음. 획득 시 카운터 리셋.

이 모드의 평균 회수율을 측정하면 실제 기계의 1/N 페이아웃과 비교 가능.

## 검증 프로토콜 (실제 기계와 비교)

### 1. 마찰계수 캘리브레이션

기준 경품 1개로 다음 실험 반복(각 50회):

| 시나리오 | 실제 기계 결과 | 시뮬 결과 | 매칭 마찰계수 |
|---|---|---|---|
| 아암 힘 약 → 슬립 발생 | … | … | … |
| 아암 힘 적정 → 들리지만 도중 떨어짐 | … | … | … |
| 아암 힘 강 → 안정적 획득 | … | … | … |

→ 실제 기계의 슬립 임계점을 시뮬레이터의 `armForce` × `friction`이 재현하도록 마찰계수를 조정.

### 2. 페이아웃 곡선

`armForce`를 0.5씩 올리며 각 값에서 100회 자동 시뮬, 회수율 곡선을 그림.
실제 기계의 設定1~10 에 해당하는 회수율과 매칭되는 `armForce` 값을 찾는다.

자동 시뮬은 콘솔에서 다음 코드로 가능 (TODO: UI 버튼화):

```js
// 브라우저 DevTools 콘솔

  for (let i = 0; i < n; i++) {
    document.getElementById('btn-drop').click();

```

### 3. 슬립 메커니즘 정성 검증

- 클로 상승 도중 발톱이 점진적으로 벌어지며 경품이 빠지는가?
- 경품이 발톱 사이를 “미끄러져” 빠지는가, 아니면 “끼인 채” 떨어지는가?
- 무거운 경품은 닫힘 직후 즉시 슬립, 가벼운 경품은 들리다가 흔들리며 슬립?

→ 모두 실제 거동과 일치해야 한다.

## 물리 모델

```
Cannon-es World (gravity = -9.81 m/s²)
├── Cabinet (정적 박스 4면 + 바닥 3분할 + 구멍 트리거)
├── Claw
│   ├── Hub: KINEMATIC body (코드로 위치 직접 제어)
│   └── Prongs (×2): DYNAMIC, mass 0.05kg each
│       └── HingeConstraint(z축) + Motor(maxForce = armForce)
└── Prizes: DYNAMIC boxes (size 0.085m, mass = prizeMass)

ContactMaterial:
  claw  ↔ prize : friction = settings.friction  (런타임 변경)
  prize ↔ prize : friction = 0.4
  prize ↔ floor : friction = 0.6
  prize ↔ wall  : friction = 0.3
```

### 모델링한 것 ✓

- 발톱 모터 토크 한계 (외부 회전을 못 막을 만큼 약하면 슬립)
- 정/동 마찰 (Cannon은 단일 계수)
- 다체 접촉 (경품 더미 위에서 발톱이 다른 경품과도 접촉)
- 경품-경품 충돌 (옆 경품을 밀치면서 잡히는 거동)
- 키네매틱 hub로 인한 정확한 클로 궤적

### 모델링하지 않은 것 ✗

- 발톱의 고무 그립(소프트 접촉) — Cannon은 강체만 지원
- 봉제인형의 변형(soft body) — 박스로 근사
- 케이블 동력학(흔들림) — 시각적 라인만
- 풍속/공조 영향
- 광학(센서로 경품 통과 감지) — 단순 좌표 검사로 대체
